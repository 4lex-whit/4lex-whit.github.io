1. In your own words, describe what a transaction is and how ACID applies.

A transaction is a set of operations carried out on a database. ACID is a set of rules applied to transactions to ensure data integrity is maintained.

2. Investigate how transactions are carried out. Investigate if there are any benefits to the way transactions are carried out.

Initiation: the transaction begins when the system or a user carries out an action. E.g. purchasing an item with a debit card.

Validation: the system checks that the transaction is valid. E.g. verifying the user has enough money in their account.

Execution: the transaction is executed, which involves multiple steps unique on the transaction. E.g. the user's money is deducted from their account and deposited into the store's.

Commitment: if all steps are completed successfully, the transaction is committed. This means changes are permanently applied to the database.

Rollback: if any step fails, then the entire transaction is rolled back. This means the database is reverted to its state before the transaction.
